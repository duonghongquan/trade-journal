# Trade Journal Riêng Tư

Web thống kê lệnh trade cá nhân, thay cho bảng tính.

## Cách dùng

1. Mở `index.html` bằng trình duyệt.
2. Nhập lệnh mới ở form phía trên.
3. Xem tổng profit, tổng R, winrate, trung bình lệnh thắng/thua và biểu đồ tăng trưởng.
4. Dùng bộ lọc theo tháng hoặc cặp giao dịch khi cần xem riêng từng giai đoạn.
5. Bấm `Xuất Excel` để tải file `.csv` theo danh sách đang lọc.

Dữ liệu được lưu trong `localStorage` của trình duyệt đang dùng trên máy này.
